# portability-articles

> [!WARNING]
> **This project is archived and no longer maintained.** The articles were written between late 2023 and late 2024 and have not been updated since. Services change their export tools, transfer options and settings often, so expect some instructions to be out of date.
>
> You are still welcome to use these articles in any way: read them, copy them, fork the repository or build on them. They are in the public domain. Just check the details against each service's current help pages before relying on them.

A public-domain collection of articles to help find solutions for data portability, created by the [Data Transfer Initiative](https://dtinit.org). This project was made to support data rights and data portability by sharing user educational material on how to exercise those rights and transfer personal data. The articles are in the [articles](articles) directory.

## How articles were structured

The project no longer accepts contributions, so pull requests and issues won't be reviewed. If you fork the repository to keep the articles going, here is how new articles and data types were added.

To create a new article:
 * Copy all the markdown in the [template file](template.md)
 * Create a new article in the articles directory
 * The article should have a permanent name that can serve as a file name - articles on porting videos can be called
   "videos1.md" "videos2.md" and so on, so if the next available name is "videos3.md" use that.
 * Paste the text from the template file in
 * Use a [supported data type](datatype-help.yaml) or add a new one (see below)

To add a new datatype:
 * Confirm it's listed in the [Content Plan file](content-plan.md)
 * Add an entry to [datatype-help.yaml](datatype-help.yaml) for the new data type
